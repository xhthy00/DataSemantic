# V02 学校科目均分及格率：实际填写示例

适用草稿：原始18表扫描草稿，模型名为tb_score/tb_exam/tb_exam_batch/tb_school。当前示例不使用此前四模型练习草稿中的exam_scores。

1. 进入“语义视图”→“添加视图”。

2. 视图名称填写：

```text
v_school_subject_score_summary
```

3. 业务说明填写：

```text
学校各科平均分及格率。输出粒度：exam_batch_id×exam_name×school_id×school_name×subject。平均分=非空成绩合计/非空成绩人数；真实0分保留。及格=成绩>=该份试卷满分×60%；及格率=及格人数/可判定人数×100。 数据范围：按exam_batch_id查询指定批次；可筛学校、科目；SQL示例保留全部已记录人群，不内置在籍过滤。0分进均分和分母，NULL成绩不进；满分缺失的有分学生计unclassified_count，不进及格率分母。null_score_count仅统计已经有记录的空成绩，不能表示全部缺考人数。 正式发布前需确认：默认在籍还是全体尚需确认；每份试卷和学校维度右键唯一，成绩(试卷,学生)无重复；负分/超满分先做质量检查
```

4. 只读语义SQL填写下面完整SELECT（不要加CREATE VIEW）：

```sql
WITH base AS (
SELECT sc.id AS score_id, sc.student_id, sc.exam_id AS paper_id,
       e.exam_batch_id, eb.batch_name AS exam_name, eb.exam_time AS exam_date,
       sc.school_id, sch.s_name AS school_name, sch.district,
       sch.type AS school_type, sc."class" AS class_name, e.subject,
       CAST(sc.score AS DECIMAL(18,4)) AS score_value,
       CAST(e.exam_score AS DECIMAL(18,4)) AS full_score,
       CASE WHEN sc.score IS NULL OR e.exam_score IS NULL
                      OR CAST(e.exam_score AS DECIMAL(18,4)) <= 0 THEN NULL
            WHEN CAST(sc.score AS DECIMAL(18,4)) >= CAST(e.exam_score AS DECIMAL(18,4)) * 0.60
            THEN 1 ELSE 0 END AS pass_flag
FROM tb_score sc
LEFT JOIN tb_exam e ON sc.exam_id = e.id
LEFT JOIN tb_exam_batch eb ON e.exam_batch_id = eb.id
LEFT JOIN tb_school sch ON sc.school_id = sch.id
)
SELECT exam_batch_id, exam_name, school_id, school_name, subject,
       COUNT(*) AS recorded_count, COUNT(score_value) AS valid_count,
       COUNT(*) - COUNT(score_value) AS null_score_count,
       SUM(score_value) AS total_score,
       ROUND(AVG(score_value),2) AS average_score,
       MIN(score_value) AS min_score, MAX(score_value) AS max_score,
       MIN(full_score) AS min_full_score, MAX(full_score) AS max_full_score,
       COALESCE(SUM(pass_flag),0) AS pass_count,
       COUNT(pass_flag) AS classified_count,
       COUNT(score_value)-COUNT(pass_flag) AS unclassified_count,
       ROUND(100.0*SUM(pass_flag)/NULLIF(COUNT(pass_flag),0),2) AS pass_rate
FROM base
GROUP BY exam_batch_id, exam_name, school_id, school_name, subject
```

5. 保存视图→保存草稿→校验；进入SQL预览：

```sql
SELECT exam_name, school_name, subject, valid_count, average_score,
       pass_count, classified_count, unclassified_count, pass_rate
FROM v_school_subject_score_summary
WHERE exam_name = '2026届高三1月期末'
ORDER BY school_name, subject;
```

6. 生成物理SQL后，在授权查询工具中对账；Studio本身不执行数据查询。

## 字段解释

| 字段 | 含义 |
|---|---|
| recorded_count | 已有科目成绩记录数，不是应考名单人数 |
| valid_count | 非空成绩人数，真实0分也计入 |
| null_score_count | 已有成绩记录里分数为空的条数，不能代表全部缺考 |
| total_score / average_score | 有效分数合计 / 平均分 |
| min_full_score / max_full_score | 当前分组卷面满分范围；可能需要检查是否混卷 |
| pass_count | 按各份卷满分60%判断后的及格人数 |
| classified_count | 有成绩且满分有效、可以判断及格的人数 |
| unclassified_count | 有成绩但缺少有效满分的人数 |
| pass_rate | 及格人数/可判定人数×100，66.67代表66.67% |

## 已验证的虚构样本

| 场景 | 预期结果 |
|---|---|
| 150分数学卷：90、0、150、NULL | 有效3，均分80，及格2，及格率66.67% |
| 100分物理卷：60、59 | 均分59.5，及格1，及格率50% |
| 有成绩80但没有试卷满分 | 均分80，未分类1，及格率NULL |
| 只有NULL成绩 | 有效0，均分NULL，及格率NULL |
| 两个不同ID的学校同名 | 按school_id保留不同分组，不因同名合并 |

## 正式发布前仍需确认

默认在籍还是全体尚需确认；每份试卷和学校维度右键唯一，成绩(试卷,学生)无重复；负分/超满分先做质量检查

本SQL学生范围为全部已记录成绩，不暗中添加在籍过滤。仅在籍需要关联已核对唯一的总览，并在聚合前筛选xsxz；不可引用tb_score并不存在的xsxz列。
当前使用学校维度type/district，不承诺学校改名、类别调整后的历史快照语义；这些可在后续版本补历史维度。
